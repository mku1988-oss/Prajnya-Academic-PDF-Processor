1. Model Profiles (olmocr-7b.yaml & olmocr-official.yaml)
Verdict: 🚨 Validation will FAIL.
Reason:
The ModelParameters sub-model is strictly defined. Your YAML files contain model-specific parameters (like min_p for olmocr-7b and gpu_memory_utilization for olmocr-official) that are not defined in the Pydantic model. Pydantic will reject these unknown fields within the parameters block and raise a ValidationError.
Additionally, useful top-level fields like status and the performance dictionary are not defined in the ModelProfile and will be ignored.
Solution:
We need to make the ModelParameters model more flexible and expand the ModelProfile to include the other useful fields. A good approach is to define the common parameters and allow any other extra parameters in a flexible dictionary.
2. Task Definitions (basic_ocr.yaml & olmocr_document_processing.yaml)
Verdict: ✅ Validation will PASS, but with data loss.
Reason:
These files will pass validation because the extra fields (task_type, description, quality_targets) are at the top level, and Pydantic ignores unknown top-level fields by default. However, this means your code would not be able to access the description or quality_targets from the loaded task_definition object, as they would be stripped out during parsing.
Solution:
We should update the TaskDefinition model to explicitly include these useful fields so they can be used within the provider.
3. Universal Config (universal_config.yaml)
Verdict: ⚠️ Misalignment between File and Code.
Reason:
The universal_config.yaml file is very comprehensive, especially with its metadata section. However, the current skeleton provider does not load this file. It creates a UniversalConfig object with hardcoded defaults: self.config = UniversalConfig().
Even if we were to load it, the entire metadata block would be ignored as it's not defined in the UniversalConfig Pydantic model.
Solution:
Update the UniversalVLMProvider to load its settings from config/universal_config.yaml.
Update the UniversalConfig Pydantic model to include the nested metadata structure.

# --- REVISED: Pydantic Models for Full YAML Compatibility ---

from pydantic import BaseModel, Field, HttpUrl, ValidationError
from typing import Dict, List, Optional, Any

# A flexible model for parameters: defines common ones, allows any others.
class ModelParameters(BaseModel):
    temperature: Optional[float] = Field(None, ge=0.0, le=2.0)
    repeat_penalty: Optional[float] = Field(None, ge=0.0)
    top_p: Optional[float] = Field(None, ge=0.0, le=1.0)
    max_tokens: Optional[int] = Field(None, gt=0)
    
    class Config:
        # Allows extra fields like 'min_p', 'gpu_memory_utilization', etc.
        extra = 'allow'

class ModelProfile(BaseModel):
    """Expanded structure for a model profile YAML to match your files."""
    model_name: str
    model_type: str
    benchmark_score: Optional[float] = None
    status: Optional[str] = None
    parameters: ModelParameters = Field(default_factory=ModelParameters)
    performance: Dict[str, Any] = {}
    capabilities: List[str] = []

class TaskDefinition(BaseModel):
    """Expanded structure for a task definition YAML to match your files."""
    task_name: str
    task_type: Optional[str] = None
    description: Optional[str] = None
    prompt: str = "Extract text from this document page accurately."
    output_format: Dict[str, Any] = {"type": "plain_text"}
    quality_targets: Dict[str, Any] = {}

# --- REVISED: Models for universal_config.yaml ---

class Metadata(BaseModel):
    """Nested metadata model for the universal config."""
    provider_type: str
    version: str
    global_settings: Dict[str, Any] = {}
    performance: Dict[str, Any] = {}
    quality: Dict[str, Any] = {}
    development: Dict[str, Any] = {}

class UniversalConfig(BaseModel):
    """Universal configuration loaded from YAML, including all metadata."""
    api_endpoint: HttpUrl = "http://localhost:8080/v1/chat/completions"
    timeout_seconds: int = 300
    default_model: str = "olmocr-7b"
    fallback_model: str = "numarkdown-8b"
    image_padding: int = 200
    conversion_dpi: int = 300
    image_format: str = "png"
    metadata: Optional[Metadata] = None # Include the whole metadata block

config_path = Path('config/universal_config.yaml')

    with open(config_path, 'r') as f:
        config_data = yaml.safe_load(f)
        self.config = UniversalConfig(**config_data)

    self.logger.error(f"Could not load or validate universal_config.yaml: {e}. Using default settings.")
